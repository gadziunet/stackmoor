SECTION A–A · BACKUP CYCLE

Every night, every stack – and proof that it can be restored.

One encrypted restic repository in your bucket holds all stacks and the panel’s own settings.

  1. 01 Dump the databases Detected automatically; the dump replaces the raw database files.
  2. 02 Snapshot each stack Its own snapshot, so one app can be restored or cloned alone.
  3. 03 Encrypt and upload B2, S3, R2, Hetzner, Wasabi or any S3-compatible storage.
  4. 04 Verify the checksums After every run, 10% read back weekly, everything on demand.
  • --schedule days + time, in your time zone
  • --keep daily / weekly / monthly
  • --pre-update backup before every update
  • --verify SHA-256 checksums
  • --restore one stack, or a clone
  • --encrypt always on, your password

DETAIL A — FIRST INSTALL
root@server:~# curl -fsSL https://raw.githubusercontent.com/gadziunet/stackmoor/main/install.sh | sudo bash
[ ok ] Docker found
[ ok ] Stacks folder: /opt/stacks
[ ok ] Stackmoor is running
➜ Open http://<server-ip>:5001 █
  1. 01 Run the command as root Docker is installed if missing. On Unraid add the image ghcr.io/gadziunet/stackmoor instead.
  2. 02 Open the panel http://<server-ip>:5001 – create the admin account.
  3. 03 Paste a compose.yaml Then add your bucket in Settings → Backups and a domain in Settings → Domains.
